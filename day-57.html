Day 57 - JavaScript Loops

🎥 Watch Tutorial #57

Loops are one of the most fundamental programming concepts. They allow us to execute a block of code repeatedly without writing the same code multiple times. JavaScript provides different types of loops such as for, while, do...while, for...in, and for...of. Choosing the right loop makes programs cleaner, faster, and easier to maintain. :contentReference[oaicite:0]{index=0}

What is a Loop?

A loop repeatedly executes a block of code until a specified condition becomes false.

Repeat ↓ Check Condition ↓ Execute Code ↓ Update Value ↓ Repeat Again

Why Do We Need Loops?

  • Avoid writing repetitive code.
  • Iterate through arrays.
  • Generate tables.
  • Process large datasets.
  • Build games.
  • Perform calculations.
  • Automate repetitive tasks.

for Loop

The for loop is the most commonly used loop when the number of iterations is known.

for(let i = 1; i <= 5; i++){ console.log(i); }

Output:

1 2 3 4 5

Structure of for Loop

for( Initialization; Condition; Update ){ // Code }
Part Purpose
Initialization Runs once
Condition Checks whether loop continues
Update Changes loop variable

while Loop

The while loop is used when the number of iterations is not known beforehand.

let i = 1; while(i <= 5){ console.log(i); i++; }

do...while Loop

The do...while loop executes the code at least once before checking the condition.

let i = 1; do{ console.log(i); i++; } while(i <= 5);

Difference

  • while checks the condition first.
  • do...while executes once before checking.

for...of Loop

The for...of loop is used to iterate through iterable objects like arrays and strings.

let fruits = ["Apple","Mango","Banana"]; for(let fruit of fruits){ console.log(fruit); }

for...in Loop

The for...in loop is mainly used to iterate through object properties.

let student = { name:"Sangam", age:20, course:"B.Tech" }; for(let key in student){ console.log(key, student[key]); }

Loop Control Statements

break

Stops the loop immediately.

for(let i=1;i<=10;i++){ if(i==5){ break; } console.log(i); }

continue

Skips the current iteration and moves to the next one.

for(let i=1;i<=5;i++){ if(i==3){ continue; } console.log(i); }

Infinite Loop

An infinite loop occurs when the condition never becomes false.

while(true){ console.log("Running"); }

Always ensure the loop variable is updated correctly to avoid infinite loops.

Nested Loops

A loop inside another loop is called a nested loop.

for(let i=1;i<=3;i++){ for(let j=1;j<=2;j++){ console.log(i,j); } }

Best Practices

  • Use for when iterations are known.
  • Use while for unknown iterations.
  • Avoid unnecessary nested loops.
  • Prevent infinite loops.
  • Use meaningful variable names.
  • Keep loop bodies small.

Common Mistakes

  • Forgetting to update the loop variable.
  • Creating infinite loops.
  • Using the wrong loop type.
  • Off-by-one errors.
  • Using for...in with arrays.

Important Points

  • Loops execute repetitive tasks.
  • for is best for fixed iterations.
  • while checks the condition first.
  • do...while runs at least once.
  • for...of works with iterables.
  • for...in iterates object properties.
  • break exits loops.
  • continue skips iterations.
  • Always update loop variables.
  • Loops are used in almost every JavaScript program.
