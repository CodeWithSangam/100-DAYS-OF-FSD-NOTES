Day 66 - Introduction to DOM, BOM & JavaScript in Browser

🎥 Watch Tutorial #66

The Document Object Model (DOM) is one of the most important concepts in JavaScript. It represents an HTML document as a tree of objects, allowing JavaScript to access, modify, create, or delete HTML elements dynamically. This tutorial also introduces the Browser Object Model (BOM), explains the difference between DOM and BOM, and demonstrates how browsers expose objects like window and document for developers. Understanding DOM is the foundation of interactive web development. :contentReference[oaicite:0]{index=0}

What is DOM?

DOM (Document Object Model) is a programming interface that represents an HTML document as a tree of objects. JavaScript uses the DOM to interact with HTML elements dynamically. :contentReference[oaicite:1]{index=1}

HTML Page ↓ Browser ↓ DOM Tree ↓ JavaScript ↓ Modify Webpage

Why Do We Need DOM?

  • Change HTML content.
  • Modify CSS styles.
  • Handle user events.
  • Create new elements.
  • Delete elements.
  • Build interactive websites.
  • Update pages without reload.

DOM Tree Structure

document │ └── html ├── head │ └── title │ └── body ├── h1 ├── p └── div

Every HTML tag becomes a node inside the DOM tree. :contentReference[oaicite:2]{index=2}

What is the document Object?

The document object represents the complete HTML page and acts as the entry point to the DOM.

console.log(document);

This prints the entire HTML document inside the browser console.

What is BOM?

BOM stands for Browser Object Model. It allows JavaScript to interact with browser features instead of webpage elements. :contentReference[oaicite:3]{index=3}

window ├── document ├── history ├── location ├── navigator ├── screen └── localStorage

DOM vs BOM

DOM BOM
Represents HTML Document Represents Browser
Uses document Uses window
Changes webpage Controls browser features
Standard API Browser-specific APIs

The window Object

The window object is the global object in browsers. Almost everything in browser JavaScript belongs to it.

console.log(window);

Examples of window properties:

  • alert()
  • prompt()
  • confirm()
  • location
  • history
  • navigator

Accessing HTML Elements

JavaScript can access HTML elements using the document object.

document.body
document.title
document.body.style.background = "lightblue";

Developer Tools

Browser Developer Tools help inspect HTML, CSS, JavaScript, and the DOM tree.

F12 ↓ Elements ↓ Console ↓ Sources ↓ Network

Console Object

The console object is used for debugging JavaScript programs.

console.log("Hello"); console.warn("Warning"); console.error("Error");

Location Object

The location object provides information about the current webpage URL.

console.log(location.href);

Common Properties

  • href
  • hostname
  • pathname
  • reload()

History Object

The history object allows navigation through browser history.

history.back(); history.forward();

Navigator Object

The navigator object contains browser and operating system information.

console.log(navigator.userAgent);

Real World Applications

Best Practices

  • Understand the DOM tree.
  • Use Developer Tools frequently.
  • Avoid modifying the DOM unnecessarily.
  • Separate HTML, CSS, and JavaScript.
  • Use console.log() while debugging.
  • Manipulate elements efficiently.

Common Mistakes

  • Confusing DOM with HTML.
  • Confusing DOM and BOM.
  • Editing the wrong DOM element.
  • Ignoring browser console errors.
  • Not understanding the DOM hierarchy.

Important Points

  • DOM represents the webpage.
  • BOM represents the browser.
  • document belongs to the DOM.
  • window is the global browser object.
  • Every HTML element becomes a DOM node.
  • JavaScript manipulates the DOM dynamically.
  • Developer Tools visualize the DOM tree.
  • Console helps debug JavaScript.
  • DOM enables interactive websites.

Final Takeaways

The DOM is the bridge between JavaScript and HTML, allowing developers to create dynamic and interactive websites. Combined with the Browser Object Model (BOM), JavaScript gains access to both webpage elements and browser functionality.
