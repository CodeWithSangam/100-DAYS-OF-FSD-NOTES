Animation Concepts Used

Concept Purpose
@keyframes Define Animation Stages
Transform Move Objects
Animation Duration Control Speed
Timing Function Smooth Motion
Iteration Count Repeat Animation

Example Structure

.ball{ animation:bounce 1s infinite; } @keyframes bounce{ 0%{ transform:translateY(0); } 50%{ transform:translateY(-200px); } 100%{ transform:translateY(0); } }

The ball moves upward and then returns to its original position.
