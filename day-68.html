Day 68 - JavaScript: Selecting Elements by ID, Classes & More

🎥 Watch Tutorial #68

Selecting HTML elements is one of the most important skills in DOM manipulation. Before JavaScript can change content, styles, attributes, or respond to events, it must first locate the desired HTML element. In this tutorial, CodeWithHarry explains the most commonly used DOM selection methods including getElementById(), getElementsByClassName(), getElementsByTagName(), querySelector(), and querySelectorAll(). These methods are used extensively in modern JavaScript development and frontend frameworks. :contentReference[oaicite:0]{index=0}

Why Element Selection is Important?

JavaScript cannot manipulate an HTML element unless it first selects that element from the DOM.

HTML ↓ DOM ↓ Select Element ↓ Modify Element

getElementById()

The getElementById() method selects a single element using its unique ID.

let heading = document.getElementById("title"); console.log(heading);

Characteristics

  • Returns one element.
  • ID should be unique.
  • Very fast selection.

getElementsByClassName()

Selects all elements having the specified class name.

let cards = document.getElementsByClassName("card"); console.log(cards);

Returns an HTMLCollection.

getElementsByTagName()

Selects all elements having the specified HTML tag.

let paragraphs = document.getElementsByTagName("p"); console.log(paragraphs);

Useful when working with multiple elements of the same type.

querySelector()

Returns the first matching element using any valid CSS selector.

document.querySelector(".card"); document.querySelector("#title"); document.querySelector("button");

Advantages

  • Uses CSS selectors.
  • Very flexible.
  • Easy to understand.

querySelectorAll()

Returns all matching elements.

let boxes = document.querySelectorAll(".box"); console.log(boxes);

Returns a NodeList that can be iterated using forEach(). :contentReference[oaicite:1]{index=1}

Changing Content

let heading = document.getElementById("title"); heading.innerHTML = "Welcome";

The selected element's content changes immediately.

Changing Styles

let heading = document.querySelector("h1"); heading.style.color = "red"; heading.style.backgroundColor = "yellow";

Selecting Multiple Elements

let items = document.querySelectorAll(".item"); items.forEach(function(item){ console.log(item); });

This is the preferred modern approach for working with multiple elements.

Best Practices

  • Prefer querySelector() for flexibility.
  • Use getElementById() for unique elements.
  • Keep IDs unique.
  • Use meaningful class names.
  • Avoid repeatedly selecting the same element.
  • Store selected elements in variables.

Common Mistakes

  • Using duplicate IDs.
  • Confusing HTMLCollection with NodeList.
  • Using querySelector() when all elements are needed.
  • Misspelling CSS selectors.
  • Trying to modify null elements.

Important Points

  • JavaScript must select elements before modifying them.
  • getElementById() selects one unique element.
  • getElementsByClassName() returns an HTMLCollection.
  • getElementsByTagName() selects by HTML tag.
  • querySelector() returns the first matching element.
  • querySelectorAll() returns a NodeList.
  • NodeList supports forEach().
  • CSS selectors work inside querySelector().
  • Store selected elements for better performance.
  • Element selection is the foundation of DOM manipulation.

Interview Questions

  1. Which method selects an element by ID?
    document.getElementById().
  2. What does querySelector() return?
    The first element matching the CSS selector.
  3. What is the difference between querySelector() and querySelectorAll()?
    querySelector() returns one element, while querySelectorAll() returns all matching elements.
  4. What does getElementsByClassName() return?
    An HTMLCollection.
  5. Which method supports CSS selectors?
    querySelector() and querySelectorAll().
  6. What is a NodeList?
    A collection of DOM nodes, commonly returned by querySelectorAll().
  7. Why should IDs be unique?
    Because getElementById() expects exactly one unique element in a document. :contentReference[oaicite:2]{index=2}
