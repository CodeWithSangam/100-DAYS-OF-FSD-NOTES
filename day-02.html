Git Configuration

Git is a version control system used to track code changes and manage project history.
Git allows developers to collaborate, manage versions, and safely maintain projects.
Used in almost every software company and development team worldwide.
Configure Git before starting projects and commit changes regularly.

Git Setup Commands

git config --global user.name "Your Name"

git config --global user.email "your@email.com"
These commands set your Git username and email globally for all repositories.

Useful VS Code Extensions

Extensions add extra functionality to VS Code and improve development speed.
They help with auto-completion, formatting, live preview, and productivity.
Live Server, Prettier, Auto Rename Tag, and HTML CSS Support are commonly used extensions.
Installing too many unnecessary extensions can slow down VS Code.

Linking CSS with HTML

CSS is linked with HTML to style and design webpages.
Without CSS, webpages only show raw content without proper design.
CSS controls colors, layouts, spacing, fonts, and responsiveness.

Link CSS File

<link rel="stylesheet" href="style.css">
The link tag connects an external CSS file with the HTML document.

Linking JavaScript with HTML

JavaScript is linked to HTML to add functionality and interactivity.
JavaScript makes websites dynamic and interactive.
Used in forms, buttons, animations, APIs, dashboards, and web applications.

Link JavaScript File

<script src="script.js"></script>
The script tag loads an external JavaScript file into the webpage.

Client-Server Interaction

The browser sends requests to a server and receives responses containing website data.
Understanding request-response flow is essential for full-stack development.
When ordering an iPhone online, your browser communicates with servers to fetch product details and process requests.

HTML, CSS, and JavaScript Roles

HTML provides structure, CSS provides styling, and JavaScript provides functionality.
These three technologies form the foundation of frontend web development.
Every modern website uses HTML, CSS, and JavaScript together.
