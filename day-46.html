Day 46 - CSS Animations

🎥 Watch Tutorial #46

CSS Animations allow developers to create complex motion effects without JavaScript. Unlike transitions, which require a change in state, animations can run automatically and repeat continuously. CSS Animations are widely used in loaders, sliders, buttons, cards, notifications, landing pages, and interactive interfaces. They make websites more engaging and improve user experience. :contentReference[oaicite:0]{index=0}

What are CSS Animations?

CSS Animations allow elements to gradually change from one style to another over time.

.box{ animation-name:move; animation-duration:2s; }

Animations can change position, size, color, rotation, opacity, and many other properties.

Why Use Animations?

  • Create interactive interfaces.
  • Improve user experience.
  • Provide visual feedback.
  • Increase engagement.
  • Build modern websites.

@keyframes Rule

The @keyframes rule defines the animation sequence.

@keyframes move{ from{ left:0; } to{ left:200px; } }

The element moves from its starting position to 200px.

animation-name

Specifies which keyframe animation should be used.

.box{ animation-name:move; }

Importance

  • Connects element to keyframes.
  • Required for animation execution.

animation-duration

Defines how long the animation takes.

.box{ animation-duration:3s; }

Units

  • Seconds (s)
  • Milliseconds (ms)

animation-iteration-count

Controls how many times the animation repeats.

.box{ animation-iteration-count:infinite; }

Values

  • 1
  • 2
  • 5
  • infinite

animation-delay

Specifies when the animation should begin.

.box{ animation-delay:1s; }

The animation starts after one second.

animation-direction

Controls the direction of animation playback.

.box{ animation-direction:alternate; }

Values

  • normal
  • reverse
  • alternate
  • alternate-reverse

animation-timing-function

Determines the speed curve of an animation.

.box{ animation-timing-function:ease; }

Common Values

  • linear
  • ease
  • ease-in
  • ease-out
  • ease-in-out

animation-fill-mode

Specifies how styles are applied before and after animation execution.

.box{ animation-fill-mode:forwards; }

Values

  • none
  • forwards
  • backwards
  • both

Shorthand Property

All animation properties can be combined into a single line.

.box{ animation: move 2s ease 1s infinite; }

Percentage Keyframes

@keyframes colorChange{ 0%{ background:red; } 50%{ background:blue; } 100%{ background:green; } }

The animation changes color gradually through different stages.

Real World Applications

  • Loading Spinners
  • Navigation Menus
  • Cards
  • Buttons
  • Image Sliders
  • Hero Sections
  • Notifications
  • Landing Pages

Common Mistakes

  • Using excessive animations.
  • Very long durations.
  • Distracting users.
  • Ignoring accessibility.
  • Overusing infinite animations.

Important Points

  • Animations are created using @keyframes.
  • animation-name links elements to keyframes.
  • Duration controls speed.
  • Iteration count controls repetition.
  • Delay postpones animation.
  • Direction changes playback order.
  • Timing functions control speed curves.
  • Fill mode controls final state.
  • Animations improve interactivity.
  • Modern websites heavily use animations.

Interview Questions

  1. What is CSS Animation?
    A technique used to gradually change CSS properties over time.
  2. What is @keyframes?
    A rule used to define animation stages.
  3. What does animation-duration do?
    It specifies how long the animation runs.
  4. What does infinite mean?
    The animation repeats forever.
  5. What is animation-fill-mode?
    It controls the final style state after animation.
  6. Can animations run without user interaction?
    Yes.
  7. What is the difference between transitions and animations?
    Transitions require a state change, while animations can run automatically.
