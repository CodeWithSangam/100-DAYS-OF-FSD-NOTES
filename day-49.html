Day 49 - CSS Object Fit and Object Position

🎥 Watch Tutorial #49

CSS Object Fit and Object Position properties are used to control how images and videos are resized and positioned inside their containers. These properties are extremely useful in responsive web design because they help maintain aspect ratios and prevent images from becoming distorted. Modern websites, image galleries, cards, profile sections, and hero banners heavily rely on these properties.

What is object-fit?

The object-fit property specifies how an image or video should fit inside its container.

img{ object-fit:cover; }

It controls whether the image should stretch, crop, or maintain its aspect ratio.

Why Use object-fit?

  • Prevents image distortion.
  • Maintains aspect ratio.
  • Creates professional layouts.
  • Improves responsiveness.
  • Useful for cards and galleries.

Default Behavior

By default, images may stretch when their width and height are forced.

img{ width:300px; height:200px; }

This can distort the image if its original aspect ratio differs.

object-fit: fill

The fill value stretches the image to occupy the entire container.

img{ object-fit:fill; }

Characteristics

  • Default value.
  • Can distort images.
  • Fills entire container.

object-fit: contain

The contain value scales the image while preserving its aspect ratio.

img{ object-fit:contain; }

Behavior

  • No cropping.
  • No distortion.
  • Empty spaces may appear.

Real World Usage

  • Logos
  • Icons
  • Product Images

object-fit: cover

The cover value fills the container while maintaining the aspect ratio.

img{ object-fit:cover; }

Behavior

  • Maintains aspect ratio.
  • Some portions may be cropped.
  • Produces attractive layouts.

Real World Usage

  • Hero Sections
  • Cards
  • Image Galleries
  • Profile Pictures

object-fit: none

The none value displays the image at its original size.

img{ object-fit:none; }

If the image is larger than the container, overflow may occur.

object-fit: scale-down

The scale-down value behaves like either none or contain, whichever results in a smaller image.

img{ object-fit:scale-down; }

Advantage

  • Preserves image quality.
  • Prevents unnecessary enlargement.

What is object-position?

The object-position property controls the position of the image inside its container.

img{ object-position:center; }

It determines which part of the image remains visible when cropping occurs.

Common Values of object-position

img{ object-position:top; }
img{ object-position:bottom; }
img{ object-position:left; }
img{ object-position:right; }
img{ object-position:center; }

Using Custom Positions

img{ object-position:20px 30px; }

The image is shifted horizontally and vertically according to the specified values.

Real World Applications

  • Image Galleries
  • Cards
  • Portfolio Websites
  • E-commerce Sites
  • Hero Sections
  • Profile Images
  • Blogs
  • Social Media Platforms

Common Mistakes

  • Forgetting width and height.
  • Using fill unnecessarily.
  • Ignoring aspect ratio.
  • Misusing object-position.
  • Choosing the wrong object-fit value.

Important Points

  • object-fit controls image resizing.
  • object-position controls image placement.
  • cover is the most commonly used value.
  • contain preserves the entire image.
  • fill can distort images.
  • none uses original image size.
  • scale-down chooses the smaller size.
  • object-position controls visible portions.
  • These properties are widely used in responsive design.
  • Modern websites depend heavily on them.
