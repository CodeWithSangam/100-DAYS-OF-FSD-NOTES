Day 30 - CSS Variables (Custom Properties)

🎥 Watch Tutorial #30

CSS Variables, also known as Custom Properties, allow developers to store reusable values inside variables and use them throughout a stylesheet. Instead of repeatedly writing the same colors, spacing values, fonts, or dimensions, we can define them once and reuse them everywhere. CSS Variables make code cleaner, easier to maintain, scalable, and highly useful in large projects. Modern frameworks, design systems, dashboards, and enterprise applications heavily rely on CSS Variables for consistency and maintainability.

What are CSS Variables?

CSS Variables are custom values defined by developers that can be reused throughout a stylesheet.

:root{ --primary-color: blue; }

The value stored inside the variable can be reused multiple times without rewriting it.

Why Use CSS Variables?

Without variables, developers must manually update every occurrence of a value whenever changes are required.

h1{ color:blue; } button{ background-color:blue; } .card{ border-color:blue; }

If the color changes, every instance must be updated manually.

Variables solve this problem by storing values in one place.

Creating a CSS Variable

Variables are created using two hyphens (--) followed by a custom name.

:root{ --primary-color:#2563eb; }

Syntax

--variable-name:value;

Best Practice

Use meaningful names that clearly describe their purpose.

Using CSS Variables

The var() function is used to access variable values.

:root{ --primary-color:#2563eb; } h1{ color:var(--primary-color); }

The heading color now comes from the variable instead of a hardcoded value.

The :root Selector

The :root selector represents the highest-level element in the document, usually the HTML element.

:root{ --main-color:red; }

Importance

  • Global access.
  • Centralized variable management.
  • Easy maintenance.
  • Project-wide consistency.

Global Variables

Variables declared inside :root become available throughout the entire webpage.

:root{ --primary:#2563eb; --secondary:#14b8a6; }
button{ background-color:var(--primary); } .card{ border-color:var(--secondary); }

Multiple components can share the same design values.

Local Variables

Variables can also be declared inside specific elements and remain available only within that scope.

.card{ --card-color:orange; background-color:var(--card-color); }

Characteristics

  • Limited scope.
  • Component-specific values.
  • Useful for reusable UI components.

Updating Themes Easily

One of the biggest advantages of CSS Variables is theme management.

:root{ --bg-color:white; --text-color:black; }
body{ background-color:var(--bg-color); color:var(--text-color); }

Changing a few variables can instantly update the entire website theme.

Dark Mode Example

Modern websites commonly use CSS Variables for dark mode implementation.

:root{ --bg-color:white; --text-color:black; } .dark-mode{ --bg-color:black; --text-color:white; }
body{ background:var(--bg-color); color:var(--text-color); }

Fallback Values

CSS allows fallback values if a variable does not exist.

color:var(--primary-color, blue);

If --primary-color is not defined, blue will be used automatically.

Benefits

  • Error prevention.
  • Improved reliability.
  • Safer component development.

Using Variables for Spacing

Variables are not limited to colors. They can store spacing values as well.

:root{ --spacing:20px; }
.card{ padding:var(--spacing); }

Benefits

  • Consistency.
  • Easy updates.
  • Cleaner design systems.

Using Variables for Fonts

Fonts can also be stored inside variables.

:root{ --main-font:Arial, sans-serif; }
body{ font-family:var(--main-font); }

Changing one variable updates typography throughout the entire website.

  • Creating too many unnecessary variables.
  • Ignoring fallback values.
  • Not organizing variables properly.
  • Mixing local and global variables incorrectly.
  • Using hardcoded values alongside variables.

CSS Variables are one of the most important features in modern CSS because they enable reusable, maintainable, and scalable styling.
