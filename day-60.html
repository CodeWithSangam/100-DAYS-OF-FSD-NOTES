Day 60 - JavaScript Strings

🎥 Watch Tutorial #60

Strings are one of the most commonly used data types in JavaScript. They represent sequences of characters enclosed in single quotes (' '), double quotes (" "), or backticks (` `). Strings are used to display text, process user input, manipulate data, format messages, and build dynamic web applications. In this tutorial, CodeWithHarry explains string creation, escape sequences, template literals, string properties, indexing, and the most frequently used string methods. What is a String?

A string is a sequence of characters used to represent textual data.

Why Use Strings?

  • Display text.
  • Store user input.
  • Create messages.
  • Build dynamic content.
  • Format output.
  • Work with APIs.
  • Manipulate text.

Creating Strings

JavaScript supports three ways to create strings.

let a = "Hello"; let b = 'World'; let c = `JavaScript`;
Quotes Use Case
" " Normal Strings
' ' Normal Strings
` ` Template Literals

String Indexing

Each character has an index starting from 0.

let name = "Harry"; console.log(name[0]); console.log(name[1]);

Output

H a

String Length

The length property returns the total number of characters.

let text = "JavaScript"; console.log(text.length);

Output

10

Template Literals

Template literals use backticks and allow variables or expressions to be embedded directly into strings.

let name = "Sangam"; console.log(`Hello ${name}`);

Output

Hello Sangam

Escape Sequence Characters

Escape sequences allow special characters inside strings.

Escape Sequence Meaning
\n New Line
\t Tab Space
\" Double Quote
\' Single Quote
\\ Backslash
console.log("Hello\nWorld");

Common String Methods

Method Purpose
toUpperCase() Uppercase Text
toLowerCase() Lowercase Text
slice() Extract Part
replace() Replace Text
concat() Join Strings
trim() Remove Extra Spaces

includes() Check Text Exists

toUpperCase() & toLowerCase()

let str = "javascript"; console.log(str.toUpperCase()); console.log(str.toLowerCase());

slice()

Extracts part of a string.

let text = "JavaScript"; console.log(text.slice(0,4));

Output

Java

replace()

let text = "Hello World"; console.log(text.replace("World","India"));

Output

Hello India

concat()

let first = "Code"; let second = "WithHarry"; console.log(first.concat(second));

trim()

let name = " Sangam "; console.log(name.trim());

Extra spaces at the beginning and end are removed.

indexOf()

let text = "JavaScript"; console.log(text.indexOf("S"));

Returns the index of the first occurrence or -1 if not found.

includes()

let course = "JavaScript"; console.log(course.includes("Script"));

Output

true

Best Practices

  • Use template literals instead of string concatenation when possible.
  • Use meaningful variable names.
  • Trim user input before validation.
  • Prefer built-in string methods.
  • Avoid unnecessary string duplication.
  • Write readable code.

Common Mistakes

  • Using the wrong quotation marks.
  • Forgetting escape sequences.
  • Ignoring string immutability.
  • Using incorrect indexes.
  • Confusing slice() with substring().

Important Points

Interview Questions

  1. What is a string in JavaScript?
    A sequence of characters enclosed in quotes.
  2. Are strings mutable?
    No, strings are immutable.
  3. What is the difference between normal strings and template literals?
    Template literals support variable interpolation and multiline strings.
  4. What does the length property return?
    The number of characters in a string.
  5. Which method converts text to uppercase?
    toUpperCase().
  6. What does trim() do?
    Removes spaces from the beginning and end of a string.
  7. Why are template literals preferred?
    They make string formatting cleaner and more readable.
