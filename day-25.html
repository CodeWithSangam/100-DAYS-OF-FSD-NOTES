Day 25 - Styling Lists using CSS

🎥 Watch Tutorial #25

In this tutorial, we learn how to style HTML lists using CSS. Lists are one of the most commonly used elements in websites. Navigation menus, sidebars, dropdowns, product categories, documentation menus, and dashboards are all built using lists. By default, HTML lists have bullets or numbers, but CSS allows us to customize their appearance completely.

What are Lists in HTML?

Lists are used to display related items together in an organized way.

Types of Lists

  • Ordered List (<ol>)
  • Unordered List (<ul>)
  • Description List (<dl>)
<ul> <li>HTML</li> <li>CSS</li> <li>JavaScript</li> </ul>

The browser automatically displays bullets before each list item.

list-style-type Property

The list-style-type property controls the appearance of bullets or numbering.

Value Output
disc ● Default Bullet
circle ○ Hollow Circle
square ■ Square Bullet
none No Bullet
decimal 1,2,3...
lower-alpha a,b,c...
upper-alpha A,B,C...
lower-roman i,ii,iii...
upper-roman I,II,III...
ul{ list-style-type:square; }

All list items will now display square bullets instead of default bullets.

Removing Bullets Completely

Most navigation menus remove default bullets because they are not required in modern website designs.

ul{ list-style-type:none; }

Real World Usage

  • Navigation Bars
  • Sidebars
  • Footer Links
  • Dashboard Menus
  • Mobile Menus

list-style-position Property

Controls where the bullet appears relative to the list content.

Value Description
outside Default Position
inside Bullet moves inside content area
ul{ list-style-position:inside; }

The bullet becomes part of the content block.

list-style-image Property

Allows developers to replace bullets with custom images.

ul{ list-style-image:url("star.png"); }

Each list item now displays a custom image instead of the default bullet.

Real World Applications

  • Feature Lists
  • Premium Plans
  • Product Benefits
  • Service Highlights

Shorthand Property

Instead of writing multiple properties separately, CSS provides a shorthand property.

ul{ list-style:square inside; }

This combines multiple list styling properties into one declaration.

Creating Navigation Menus using Lists

Most website navigation bars are actually unordered lists styled using CSS.

<ul> <li>Home</li> <li>About</li> <li>Services</li> <li>Contact</li> </ul>
ul{ list-style:none; display:flex; gap:20px; }

This converts a vertical list into a horizontal navigation menu.

Modern Menu Styling

Modern websites combine list styling with Flexbox to build professional navigation systems.

ul{ display:flex; list-style:none; justify-content:center; gap:25px; }

This approach is used by almost every modern website.

Important Points
