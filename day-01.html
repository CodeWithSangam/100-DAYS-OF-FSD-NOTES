What is VS Code?

VS Code (Visual Studio Code) is a lightweight and powerful code editor used by developers to write HTML, CSS, JavaScript, Python, and many other programming languages.
It improves productivity through extensions, syntax highlighting, IntelliSense, debugging, terminal support, and Git integration.
Used by frontend developers, backend developers, full-stack engineers, AI developers, and software companies worldwide.
Install useful extensions only when needed instead of filling VS Code with unnecessary plugins.
Beginners often install too many extensions and create confusion in their workflow.

How Websites Work

A website is a collection of files stored on a server and accessed through a browser using the internet.
Understanding this architecture is the foundation of web development.
When you open youtube.com, your browser sends a request to YouTube servers, and the server responds with website data.
Every application such as YouTube, Facebook, Amazon, Netflix, and Instagram follows this architecture.

Client and Server

Client = User Device (Browser)
Server = Computer that stores website files and data
Every web application depends on communication between client and server.
Browser → Request → Server
Server → Response → Browser

HTML Introduction

HTML (HyperText Markup Language) is used to create the structure of webpages.
HTML acts as the skeleton of every website.
Used in every web application regardless of framework or technology stack.

First HTML File

<!DOCTYPE html>
<html>
<head>
    <title>My First Website</title>
</head>
<body>
    Hello World
</body>
</html>
DOCTYPE tells browser this is an HTML5 document.
html contains the entire webpage.
head contains metadata and title.
body contains visible content shown to users.

Domain and Hosting

Domain = Website Name (example.com)
Hosting = Server space where website files are stored.
Both are required to make a website accessible on the internet.
