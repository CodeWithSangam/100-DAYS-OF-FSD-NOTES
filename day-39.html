CSS Grid is a powerful two-dimensional layout system introduced to simplify the creation of complex web layouts. Unlike Flexbox, which mainly works in one dimension (row or column), CSS Grid handles rows and columns simultaneously. It provides precise control over element placement and is widely used in dashboards, galleries, admin panels, magazine layouts, and modern responsive websites. CSS Grid is one of the most important technologies in modern frontend development. :contentReference[oaicite:0]{index=0}

What is CSS Grid?

CSS Grid is a layout system that allows developers to arrange elements in rows and columns.

.container{ display:grid; }

After applying display:grid, the container becomes a grid container and its child elements become grid items.

Why CSS Grid?

Before Grid, developers used Float, Position, and Flexbox to create layouts. Grid simplifies the creation of complex two-dimensional structures.

Advantages

  • Supports rows and columns simultaneously.
  • Cleaner code.
  • Highly responsive.
  • Precise element placement.
  • Suitable for complex layouts.

Creating a Grid Container

.container{ display:grid; }

This enables all Grid properties for the container.

grid-template-columns

Defines the number and width of columns.

.container{ display:grid; grid-template-columns:100px 100px 100px; }

Result

  • Three columns are created.
  • Each column has a width of 100px.

Using Fraction Units (fr)

The fr unit divides available space proportionally.

.container{ grid-template-columns:1fr 2fr 1fr; }

Meaning

  • First column gets one part.
  • Second column gets two parts.
  • Third column gets one part.

grid-template-rows

Defines the height of rows.

.container{ grid-template-rows:100px 200px; }

The first row has a height of 100px and the second row has a height of 200px.

Gap Property

Gap creates spacing between rows and columns.

.container{ gap:20px; }

Benefits

  • Cleaner layouts.
  • No need for margins.
  • Consistent spacing.

Repeat Function

The repeat() function reduces repetitive code.

.container{ grid-template-columns: repeat(3,1fr); }

This creates three equal columns.

Grid Item Placement

Individual items can span multiple rows or columns.

.item{ grid-column:1/3; }

The item occupies columns 1 and 2.

Row Example

.item{ grid-row:1/3; }

The item occupies rows 1 and 2.

justify-items Property

Aligns items horizontally inside grid cells.

.container{ justify-items:center; }

Values

  • start
  • center
  • end
  • stretch

align-items Property

Controls vertical alignment inside cells.

.container{ align-items:center; }

Usage

  • Centering content.
  • Card layouts.
  • Dashboard designs.

Grid vs Flexbox

Grid Flexbox
Two-Dimensional One-Dimensional
Rows and Columns Row OR Column
Complex Layouts Alignment
Dashboards Navigation Bars

Common Mistakes

  • Confusing Grid with Flexbox.
  • Using fixed widths everywhere.
  • Ignoring fr units.
  • Not using repeat().
  • Creating overly complex grids.

Important Points

  • display:grid activates Grid.

  • fr units distribute space proportionally.

  • Grid and Flexbox complement each other.
