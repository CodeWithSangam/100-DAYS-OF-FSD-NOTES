Day 76 - Async/Await and Fetch API in JavaScript

🎥 Watch Tutorial #76

In this tutorial, we learn about async functions, the await keyword, the Fetch API, JSON data, HTTP requests, API responses, error handling, and try-catch-finally in JavaScript. Async and await provide a cleaner way to work with promises, while the Fetch API allows JavaScript applications to communicate with external servers and receive data without reloading the webpage.

What is Asynchronous JavaScript?

Asynchronous JavaScript allows time-consuming operations to complete without blocking the remaining JavaScript code.

Start Operation ↓ Continue Running Other Code ↓ Wait for Asynchronous Result ↓ Process the Result

Operations such as API requests, timers, file loading, and database communication are usually asynchronous.

Why Do We Need Asynchronous JavaScript?

  • Fetch data from an API.
  • Send data to a server.
  • Load external files.
  • Upload images and documents.
  • Handle database operations.
  • Process online payments.
  • Load content without refreshing the page.
  • Prevent the webpage from becoming unresponsive.

What is an Async Function?

An async function is a function declared using the async keyword. It always returns a promise.

async function greet() { return "Hello JavaScript"; } console.log(greet());

Even though the function returns a string, JavaScript automatically wraps the value inside a fulfilled promise.

Handling an Async Function Result

async function greet() { return "Hello Sangam"; } greet() .then(function(message) { console.log(message); });

Because an async function returns a promise, its result can be handled using then().

Async Function Using Arrow Syntax

const greet = async () => { return "Hello from async function"; }; greet() .then(function(result) { console.log(result); });

What is the await Keyword?

The await keyword pauses an async function until a promise is settled. It then returns the fulfilled value of that promise.

async function getResult() { let promise = new Promise(function(resolve) { setTimeout(function() { resolve("Task completed"); }, 2000); }); let result = await promise; console.log(result); } getResult();

The async function waits for the promise result before executing the next statement inside that function.

Important Rule of await

The await keyword is normally used inside an async function.

async function showMessage() { let result = await Promise.resolve("Message received"); console.log(result); } showMessage();

Incorrect Example

function showMessage() { let result = await Promise.resolve("Hello"); }

Using await inside a normal function produces an error.

Promise Using then()

function getData() { return new Promise(function(resolve) { setTimeout(function() { resolve("Data received"); }, 2000); }); } getData() .then(function(result) { console.log(result); });

Same Promise Using Async/Await

function getData() { return new Promise(function(resolve) { setTimeout(function() { resolve("Data received"); }, 2000); }); } async function displayData() { let result = await getData(); console.log(result); } displayData();

Async and await make asynchronous code look similar to normal synchronous code.

Promise Chaining vs Async/Await

Promise Chaining Async/Await
Uses multiple then() methods Uses await inside an async function
Can become lengthy Looks cleaner and more readable
Uses catch() for errors Usually uses try-catch
Useful for promise pipelines Useful for sequential asynchronous tasks

Running Multiple Tasks Sequentially

function firstTask() { return new Promise(function(resolve) { setTimeout(function() { resolve("First task completed"); }, 1000); }); } function secondTask() { return new Promise(function(resolve) { setTimeout(function() { resolve("Second task completed"); }, 1000); }); } async function runTasks() { let firstResult = await firstTask(); console.log(firstResult); let secondResult = await secondTask(); console.log(secondResult); } runTasks();

The second task starts after the first awaited task is completed.

Error Handling with try-catch

The try-catch statement is commonly used to handle errors inside async functions.

async function getResult() { try { let result = await Promise.reject( new Error("Operation failed") ); console.log(result); } catch (error) { console.log(error.message); } } getResult();

If the awaited promise is rejected, JavaScript moves directly to the catch block.

Using finally with Async/Await

The finally block executes whether the asynchronous operation succeeds or fails.

async function performTask() { try { let result = await Promise.resolve( "Task completed" ); console.log(result); } catch (error) { console.log(error.message); } finally { console.log("Operation finished"); } } performTask();

The finally block is useful for hiding loaders, closing connections, and performing cleanup.

What is the Fetch API?

The Fetch API is a browser feature used to send HTTP requests and receive responses from a server.

fetch("https://jsonplaceholder.typicode.com/posts")

The fetch() function immediately returns a promise containing a Response object.

Basic Fetch Request

fetch("https://jsonplaceholder.typicode.com/posts") .then(function(response) { console.log(response); });

The response contains information such as the HTTP status, headers, URL, and response body.

Converting Response into JSON

The response body must be converted into usable JavaScript data. The response.json() method converts JSON data into JavaScript objects or arrays.

fetch("https://jsonplaceholder.typicode.com/posts") .then(function(response) { return response.json(); }) .then(function(data) { console.log(data); });

The json() method also returns a promise, so another then() method is required.

Fetch API Using Async/Await

async function getPosts() { let response = await fetch( "https://jsonplaceholder.typicode.com/posts" ); let data = await response.json(); console.log(data); } getPosts();

The first await waits for the server response. The second await waits for the response body to be converted into JavaScript data.

Why Two await Keywords are Used?

let response = await fetch(url); let data = await response.json();
Statement Purpose
await fetch(url) Waits for the server response
await response.json() Waits for JSON conversion

Complete Fetch Example

async function getUsers() { try { let response = await fetch( "https://jsonplaceholder.typicode.com/users" ); let users = await response.json(); console.log(users); } catch (error) { console.log("Error:", error.message); } } getUsers();

Checking the Response Status

The Fetch API does not automatically reject every unsuccessful HTTP response. We should check the response.ok property.

async function getData() { try { let response = await fetch( "https://jsonplaceholder.typicode.com/posts" ); if (!response.ok) { throw new Error( "HTTP error: " + response.status ); } let data = await response.json(); console.log(data); } catch (error) { console.log(error.message); } } getData();

Important Response Properties

Property Meaning
response.ok Returns true when the request is successful
response.status Returns the HTTP status code
response.statusText Returns the HTTP status message
response.url Returns the final response URL
response.headers Contains response header information

Common HTTP Status Codes

Status Code Meaning

201 Resource created successfully
204 Request successful with no response body
400 Bad request
401 Authentication required
403 Access forbidden
404 Resource not found
500 Internal server error

Displaying API Data on the Webpage

<div id="user-container"></div> let container = document.querySelector("#user-container"); async function getUsers() { let response = await fetch( "https://jsonplaceholder.typicode.com/users" ); let users = await response.json(); users.forEach(function(user) { let card = document.createElement("div"); card.classList.add("user-card"); card.innerHTML = ` <h3>${user.name}</h3> <p>${user.email}</p> `; container.append(card); }); } getUsers();

The API data is converted into HTML cards and inserted dynamically into the DOM.

Fetching a Single Record

async function getPost() { let response = await fetch( "https://jsonplaceholder.typicode.com/posts/1" ); let post = await response.json(); console.log(post.title); console.log(post.body); } getPost();

GET Request

A GET request is used to retrieve data from a server. fetch() performs a GET request by default.

async function getProducts() { let response = await fetch( "https://example.com/api/products" ); let products = await response.json(); console.log(products); }

POST Request

A POST request is used to send new data to a server.

async function createPost() { let response = await fetch( "https://jsonplaceholder.typicode.com/posts", { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ title: "JavaScript Fetch API", body: "Learning POST requests", userId: 1 }) } ); let data = await response.json(); console.log(data); } createPost();

Why JSON.stringify() is Used?

JSON.stringify() converts a JavaScript object into a JSON string before sending it to the server.

let user = { name: "Sangam", role: "Developer" }; let jsonData = JSON.stringify(user); console.log(jsonData);
Method Purpose
JSON.stringify() Converts JavaScript data into JSON string
JSON.parse() Converts JSON string into JavaScript data
response.json() Reads and converts a JSON response body

Request Headers

Headers provide additional information about an HTTP request or response.

headers: { "Content-Type": "application/json", "Authorization": "Bearer token-value" }

The Content-Type header informs the server that JSON data is being sent.

PUT Request

A PUT request is commonly used to update an entire existing resource.

async function updatePost() { let response = await fetch( "https://jsonplaceholder.typicode.com/posts/1", { method: "PUT", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ id: 1, title: "Updated Post", body: "Updated content", userId: 1 }) } ); let data = await response.json(); console.log(data); } updatePost();

PATCH Request

A PATCH request is commonly used to update selected properties of an existing resource.

async function updateTitle() { let response = await fetch( "https://jsonplaceholder.typicode.com/posts/1", { method: "PATCH", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ title: "New Title" }) } ); let data = await response.json(); console.log(data); } updateTitle();

DELETE Request

A DELETE request is used to remove a resource from the server.

async function deletePost() { let response = await fetch( "https://jsonplaceholder.typicode.com/posts/1", { method: "DELETE" } ); if (response.ok) { console.log("Post deleted successfully"); } } deletePost();

HTTP Request Methods

Method Purpose
GET Retrieve data
POST Create new data
PUT Replace or update complete data
PATCH Update part of existing data
DELETE Remove data

Using a Loading Message

let statusMessage = document.querySelector("#status"); async function loadData() { try { statusMessage.innerText = "Loading..."; let response = await fetch( "https://jsonplaceholder.typicode.com/users" ); if (!response.ok) { throw new Error("Unable to load users"); } let users = await response.json(); console.log(users); statusMessage.innerText = "Data loaded successfully"; } catch (error) { statusMessage.innerText = "Error: " + error.message; } } loadData();

Using finally for a Loader

let loader = document.querySelector("#loader"); async function loadUsers() { try { loader.style.display = "block"; let response = await fetch( "https://jsonplaceholder.typicode.com/users" ); if (!response.ok) { throw new Error("Request failed"); } let users = await response.json(); console.log(users); } catch (error) { console.log(error.message); } finally { loader.style.display = "none"; } } loadUsers();

The loader is hidden in the finally block whether the request succeeds or fails.

Handling Form Submission with Fetch

let form = document.querySelector("#userForm"); form.addEventListener("submit", async function(event) { event.preventDefault(); let name = document.querySelector("#name").value; let email = document.querySelector("#email").value; try { let response = await fetch( "https://example.com/api/users", { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ name: name, email: email }) } ); if (!response.ok) { throw new Error("Form submission failed"); } let result = await response.json(); console.log(result); } catch (error) { console.log(error.message); } });

Fetch API Error Handling

A proper Fetch API request should handle both network errors and unsuccessful HTTP status codes.

async function fetchData(url) { try { let response = await fetch(url); if (!response.ok) { throw new Error( "Request failed with status " + response.status ); } let data = await response.json(); return data; } catch (error) { console.log("Fetch error:", error.message); throw error; } }

Network Error vs HTTP Error

Network Error HTTP Error
No internet connection Server returns 404 or 500
DNS or connection failure A response is still received
fetch() promise may reject fetch() may still fulfil
Handled by catch Check response.ok manually

Running Requests Sequentially

async function loadSequentially() { let userResponse = await fetch( "https://jsonplaceholder.typicode.com/users/1" ); let user = await userResponse.json(); let postResponse = await fetch( "https://jsonplaceholder.typicode.com/posts?userId=" + user.id ); let posts = await postResponse.json(); console.log(user); console.log(posts); } loadSequentially();

The second request depends on information received from the first request.

Running Independent Requests Together

When multiple asynchronous operations do not depend on one another, Promise.all() can run them together.

async function loadAllData() { let requests = await Promise.all([ fetch( "https://jsonplaceholder.typicode.com/users" ), fetch( "https://jsonplaceholder.typicode.com/posts" ) ]); let data = await Promise.all([ requests[0].json(), requests[1].json() ]); console.log(data[0]); console.log(data[1]); } loadAllData();

Reusable Fetch Function

async function getJSON(url) { let response = await fetch(url); if (!response.ok) { throw new Error( "HTTP error: " + response.status ); } return response.json(); } async function displayPosts() { try { let posts = await getJSON( "https://jsonplaceholder.typicode.com/posts" ); console.log(posts); } catch (error) { console.log(error.message); } } displayPosts();

Async Function Return Value

Every async function returns a promise, even when no await keyword is used.

async function getNumber() { return 100; } getNumber() .then(function(number) { console.log(number); });

Throwing an Error Inside Async Function

Throwing an error inside an async function returns a rejected promise.

async function checkAge(age) { if (age < 18) { throw new Error("User is under 18"); } return "User is eligible" ; } checkAge(16) .then(function(message) { console.log(message); }) .catch(function(error) { console.log(error.message); });

Best Practices

  • Use async and await for readable asynchronous code.
  • Use try-catch to handle errors.
  • Always check response.ok after fetch().
  • Use Error objects for meaningful errors.
  • Display loading and error states to users.
  • Use finally for cleanup operations.
  • Avoid unnecessary sequential requests.
  • Use Promise.all() for independent requests.
  • Create reusable API request functions.
  • Never expose secret API keys in frontend code.
  • Validate data before sending it to a server.
  • Use JSON.stringify() when sending JSON data.

Common Mistakes

  • Using await outside an async function.
  • Forgetting that async functions return promises.
  • Forgetting to await response.json().
  • Not checking response.ok.
  • Assuming fetch rejects for every HTTP error.
  • Forgetting to handle network errors.
  • Using incorrect API URLs.
  • Forgetting JSON.stringify() in POST requests.
  • Not setting the Content-Type header.
  • Sending private API keys from frontend JavaScript.
  • Running independent requests sequentially.
  • Ignoring loading and error messages.

Interview Questions

  1. What is an async function?
    An async function is a function declared with the async keyword that always returns a promise.
  2. What does the await keyword do?
    It pauses an async function until a promise is settled and returns its fulfilled value.
  3. Can await be used inside a normal function?
    No. It is normally used inside an async function.
  4. Does await block the complete JavaScript program?
    No. It pauses only the current async function while other JavaScript operations can continue.
  5. What is the Fetch API?
    The Fetch API is a browser feature used to send HTTP requests and receive server responses.
  6. What does fetch() return?
    It returns a promise containing a Response object.
  7. Why is response.json() awaited?
    Because reading and converting the response body is asynchronous and returns a promise.
  8. What is response.ok?
    It is a boolean property indicating whether the HTTP response was successful.
  9. Does fetch() reject for a 404 response?
    It may still fulfil with a Response object, so response.ok should be checked manually.
  10. What is the purpose of try-catch?
    It handles errors generated during asynchronous operations.
  11. What does finally do?
    It executes after try-catch whether the operation succeeds or fails.
  12. What is an API?
    An API is an interface that allows different software applications to communicate.
  13. What is the difference between GET and POST?
    GET retrieves data, while POST sends data to create a new resource.
  14. Why is JSON.stringify() used?
    It converts a JavaScript object into a JSON string before sending it.
  15. What is the Content-Type header?
    It tells the server the format of the request body, such as application/json.
  16. What is Promise.all()?
    It waits for multiple promises and fulfils when all of them fulfil.
  17. What happens when an async function throws an error?
    The async function returns a rejected promise.
  18. What is the difference between then() and await?
    Both consume promises, but await usually provides cleaner sequential asynchronous code.

Final Takeaways

Async and await provide a clean and readable way to handle promises in JavaScript. An async function always returns a promise, while await pauses that function until an asynchronous operation is settled. The Fetch API allows web applications to communicate with servers through HTTP requests. By combining fetch(), response.json(), response.ok, try-catch-finally, request methods, headers, and JSON conversion, developers can create applications that load, create, update, and delete server data dynamically. These concepts are essential for weather apps, dashboards, authentication systems, e-commerce websites, AI applications, job portals, and other modern web applications.
