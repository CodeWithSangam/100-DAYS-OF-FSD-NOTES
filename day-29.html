Day 29 - Exercise 3: Design This Card

🎥 Watch Tutorial #29

Exercise 3 is a practical CSS challenge where students are asked to recreate a professional-looking card design using the concepts learned so far. The goal is not to learn a new CSS property but to strengthen problem-solving skills by combining multiple CSS concepts such as Box Model, Colors, Borders, Border Radius, Typography, Overflow, Display Properties, Shadows, and Positioning. Understanding Card Components

Cards are reusable UI components that group related information into a visually separate container.

Typical Card Elements

  • Image
  • Category Tags
  • Title
  • Description
  • Button

Real World Usage

  • Blog Posts
  • Product Listings
  • Course Cards
  • Portfolio Projects
  • News Articles
  • User Profiles

HTML Structure of the Card

A clean HTML structure makes styling easier and improves maintainability.

<div class="card"> <img src="image.jpg"> <div class="tags"> <span>Nature</span> <span>Lake</span> </div> <h2>Lago di Braies</h2> <p> A beautiful lake located in Italy. </p> <button> Read More </button> </div>

Each section of the card has a clear responsibility which improves organization and readability.

Creating the Card Container

The card container acts as the main wrapper for all card elements.

.card{ width:300px; background:white; border-radius:12px; padding:10px; }

Benefits

  • Creates a defined layout.
  • Groups related content.
  • Improves visual structure.

Using Border Radius

Border radius creates rounded corners and gives modern applications a polished appearance.

.card{ border-radius:15px; }

Real World Usage

  • Cards
  • Buttons
  • Forms
  • Navigation Menus
  • Mobile Applications

Image Styling

Images should fit inside the card without breaking layout consistency.

img{ width:100%; border-radius:10px; }

Importance

  • Responsive Design
  • Consistent Layout
  • Professional Appearance

Designing Category Tags

Tags provide additional context and help categorize content.

.tag{ border:1px solid gray; padding:5px 12px; border-radius:20px; }

Examples

  • Nature
  • Travel
  • Technology
  • Photography

Applying Box Shadows

Box shadows create depth and visual hierarchy.

.card{ box-shadow: 0px 4px 15px rgba(0,0,0,0.15); }

Benefits

  • Creates Elevation
  • Improves Visibility
  • Makes UI Modern

Typography and Content Styling

Typography affects readability and user experience.

h2{ font-size:24px; } p{ color:gray; line-height:1.6; }

Best Practices

  • Maintain readable font sizes.
  • Use proper spacing.
  • Create hierarchy with headings.
  • Avoid excessive text.

Button Design

Buttons encourage users to interact with the interface.

button{ padding:10px 20px; border:none; border-radius:20px; background-color:lightblue; cursor:pointer; }

Best Practices

  • Use meaningful labels.
  • Provide hover effects.
  • Maintain accessibility.
  • Use consistent colors.

Centering the Button

Proper alignment improves visual balance.

.button-container{ text-align:center; }

This technique is commonly used in cards and landing pages.
