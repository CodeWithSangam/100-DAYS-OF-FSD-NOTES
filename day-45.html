Day 45 - CSS Transition Property

🎥 Watch Tutorial #45

CSS Transitions allow developers to smoothly change property values over a specified duration instead of making changes instantly. Transitions are widely used to create interactive and visually appealing user interfaces. Buttons, cards, navigation menus, forms, and hover effects often rely on transitions to provide a better user experience. CSS Transitions are one of the most important concepts in modern frontend development. :contentReference[oaicite:0]{index=0}

What is CSS Transition?

A transition creates a smooth animation between two states of an element.

.box{ transition: all 1s; }

Instead of changing immediately, the element gradually changes over one second.

Why Use Transitions?

  • Create smooth effects.
  • Improve user experience.
  • Make interfaces interactive.
  • Add professionalism to websites.
  • Enhance visual feedback.

Transition Syntax

transition: property duration timing-function delay;

Example

transition: background-color 1s ease 0s;

transition-property

Specifies which property should animate.

.box{ transition-property:background-color; }

Examples

  • width
  • height
  • color
  • background-color
  • transform

transition-duration

Defines how long the transition should take.

.box{ transition-duration:2s; }

Units

  • s (seconds)
  • ms (milliseconds)

transition-timing-function

Controls the speed curve of the transition.

.box{ transition-timing-function:ease; }

Common Values

  • linear
  • ease
  • ease-in
  • ease-out
  • ease-in-out

transition-delay

Specifies when the transition should begin.

.box{ transition-delay:1s; }

The animation starts after one second.

Shorthand Property

All transition properties can be combined into one line.

.box{ transition: all 1s ease; }

This is the most commonly used approach.

Hover Effects

Transitions are frequently combined with :hover.

button{ background-color:blue; transition:all .5s ease; } button:hover{ background-color:red; }

The color changes smoothly when the user hovers over the button.

Transition with Transform

.card{ transition:all .5s ease; } .card:hover{ transform:scale(1.1); }

Interview Questions

  1. What is CSS Transition?

  2. What are the four components of a transition?
    Property, duration, timing function, and delay.
  3. What does transition-duration do?
    It specifies how long the transition lasts.
  4. Which timing function creates constant speed?
    linear.
  5. Why are transitions used?
    To improve user experience and interactivity.
  6. Can transitions work with transforms?
    Yes.
  7. Which pseudo-class is commonly used with transitions?
    :hover.
