Day 63 - JavaScript Arrays

🎥 Watch Tutorial #63

Arrays are one of the most important data structures in JavaScript. They allow us to store multiple values inside a single variable instead of creating separate variables for each value. Arrays can store numbers, strings, objects, functions, and even other arrays. They are extensively used in web applications to manage collections of data such as products, users, comments, shopping carts, API responses, and much more. Mastering arrays is essential before learning loops with arrays, higher-order functions, and advanced JavaScript concepts. :contentReference[oaicite:0]{index=0}

What is an Array?

An array is an ordered collection of multiple values stored inside square brackets [].

let fruits = ["Apple", "Mango", "Banana"]; console.log(fruits);

Why Use Arrays?

  • Store multiple values.
  • Reduce unnecessary variables.
  • Easy data management.
  • Efficient looping.
  • Simplifies programming.
  • Supports dynamic applications.

Creating Arrays

let numbers = [10,20,30]; let names = ["Harry","Sangam","Rohan"]; let mixed = [1,"Hello",true];

JavaScript arrays can contain values of different data types.

Array Indexing

Array indexing starts from 0.

let fruits = ["Apple","Mango","Banana"]; console.log(fruits[0]); console.log(fruits[2]);

Output

Apple Banana

Array Length

The length property returns the total number of elements.

let fruits = ["Apple","Mango","Banana"]; console.log(fruits.length);

Output

3

Updating Array Elements

let fruits = ["Apple","Mango","Banana"]; fruits[1] = "Orange"; console.log(fruits);

Arrays are mutable, meaning their elements can be changed after creation.

Converting Array to String

let arr = [1,2,3]; console.log(arr.toString());

Output

1,2,3

join()

The join() method combines array elements using a separator.

let fruits = ["Apple","Mango","Banana"]; console.log(fruits.join(" - "));

Output

Apple - Mango - Banana

pop()

Removes the last element from the array.

let fruits = ["Apple","Mango","Banana"]; fruits.pop(); console.log(fruits);

push()

Adds a new element at the end of the array.

let fruits = ["Apple","Mango"]; fruits.push("Banana"); console.log(fruits);

shift()

Removes the first element of an array.

let fruits = ["Apple","Mango","Banana"]; fruits.shift(); console.log(fruits);

unshift()

Adds an element to the beginning of an array.

let fruits = ["Mango","Banana"]; fruits.unshift("Apple"); console.log(fruits);

delete Operator

The delete operator removes an element but does not change the array length.

let arr = [1,2,3]; delete arr[1]; console.log(arr);

Important

Using delete creates empty slots. It is generally better to use splice().

concat()

Combines two or more arrays into one new array.

let a = [1,2]; let b = [3,4]; console.log(a.concat(b));

Output

[1,2,3,4]

sort()

Sorts array elements alphabetically by default.

let fruits = ["Banana","Apple","Mango"]; fruits.sort(); console.log(fruits);

reverse()

Reverses the order of array elements.

let numbers = [1,2,3]; numbers.reverse(); console.log(numbers);

splice()

Adds, removes, or replaces elements in an array.

let arr = [1,2,3,4]; arr.splice(1,2); console.log(arr);

slice()

Returns a portion of an array without modifying the original array.

let arr = [10,20,30,40]; console.log(arr.slice(1,3));

Output

[20,30]

Real World Applications

  • Shopping Cart.
  • Student Records.
  • Employee Lists.
  • API Responses.
  • Product Catalogs.
  • Chat Messages.
  • Image Galleries.
  • Todo Applications.

Best Practices

  • Use descriptive array names.
  • Prefer splice() over delete.
  • Use const when the array reference doesn't change.
  • Avoid unnecessary nested arrays.
  • Keep arrays organized.
  • Choose the right array method.

Common Mistakes

  • Confusing slice() and splice().
  • Using delete on arrays.
  • Ignoring zero-based indexing.
  • Accessing invalid indexes.
  • Expecting sort() to sort numbers correctly without a compare function.

Important Points

  • Arrays store multiple values.
  • Indexing starts from zero.
  • Arrays are mutable.
  • length returns total elements.
  • push() adds to the end.
  • pop() removes from the end.
  • shift() removes from the beginning.
  • unshift() adds to the beginning.
  • splice() modifies arrays.
  • slice() returns a new array.

Interview Questions

  1. What is an array?
    A collection of multiple values stored in a single variable.
  2. Are JavaScript arrays mutable?
    Yes.
  3. What is the difference between slice() and splice()?
    slice() returns a new array, while splice() modifies the original array.
  4. What does push() do?
    Adds an element to the end.
  5. What does pop() do?
    Removes the last element.
  6. Why should delete be avoided with arrays?
    It leaves empty slots and doesn't change the array length.
  7. What property returns the number of elements?
    length.
