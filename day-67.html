Day 67 - DOM: Children, Parent & Sibling Nodes

🎥 Watch Tutorial #67

In this tutorial, CodeWithHarry explains how HTML elements are connected inside the DOM as a tree structure. Every element has relationships such as parent, child, and sibling. Understanding these relationships allows developers to traverse the DOM efficiently without repeatedly searching the document. DOM traversal is an essential skill for building interactive web applications and manipulating webpage elements dynamically. :contentReference[oaicite:0]{index=0}

DOM Tree Relationship

Every HTML document is represented as a tree where each element becomes a node.

html │ ├── head │ └── body     ├── h1     ├── div     │  ├── p     │  └── button     └── footer

This tree structure makes navigation between elements easy using JavaScript. :contentReference[oaicite:1]{index=1}

Types of DOM Nodes

Node Type Description
Element Node HTML Tags
Text Node Text Inside Elements
Comment Node HTML Comments
Document Node Entire HTML Document

Parent Node

A parent node is the element that directly contains another element.

let child = document.querySelector("p"); console.log(child.parentElement);

Output:

<div>...</div>

Child Nodes

Child nodes are elements that exist directly inside another element.

let box = document.querySelector(".container"); console.log(box.children);

The children property returns only HTML element nodes.

childNodes vs children

children childNodes
Only HTML Elements Elements + Text + Comments
Returns HTMLCollection Returns NodeList
Ignores whitespace text Includes whitespace nodes

Accessing First and Last Child

let box = document.querySelector(".container"); console.log(box.firstElementChild); console.log(box.lastElementChild);

Output

Returns the first and last HTML child elements.

Parent Element

let heading = document.querySelector("h1"); console.log(heading.parentElement);

Returns the immediate parent element of the selected node.

Sibling Elements

Elements having the same parent are called sibling elements.

  

  

Here, h1 and p are siblings.

nextElementSibling

Returns the next sibling element.

let heading = document.querySelector("h1"); console.log(heading.nextElementSibling);

previousElementSibling

Returns the previous sibling element.

let paragraph = document.querySelector("p"); console.log(paragraph.previousElementSibling);

firstChild vs firstElementChild

firstChild firstElementChild
May Return Text Node Always Returns HTML Element
Includes Spaces Ignores Spaces

lastChild vs lastElementChild

lastChild lastElementChild
May Return Text Node Returns Last HTML Element
Includes Comments Ignores Comments

HTMLCollection vs NodeList

HTMLCollection NodeList
Contains Elements Only Can Contain Different Node Types
Live Collection Usually Static Collection

Best Practices

  • Prefer children over childNodes when working with HTML elements.
  • Use parentElement instead of parentNode when manipulating HTML.
  • Understand the DOM tree before writing JavaScript.
  • Use meaningful class names.
  • Avoid unnecessary DOM traversal.
  • Inspect the DOM using Developer Tools.

Common Mistakes

  • Confusing childNodes with children.
  • Ignoring text nodes created by whitespace.
  • Using wrong sibling methods.
  • Traversing the DOM unnecessarily.
  • Forgetting that indexing starts from zero.

Important Points

  • Every HTML element is a DOM node.
  • DOM follows a tree structure.
  • Parent nodes contain child nodes.
  • Siblings share the same parent.
  • children returns only HTML elements.
  • childNodes includes text and comment nodes.
  • Use firstElementChild for HTML elements.
  • Use nextElementSibling to move forward.
  • Use previousElementSibling to move backward.
  • DOM traversal is essential for frontend development.

Interview Questions

  1. What is DOM traversal?
    Navigating between elements using parent, child, and sibling relationships.
  2. What is the difference between childNodes and children?
    children returns only HTML elements, while childNodes includes text and comment nodes.
  3. What does parentElement return?
    The immediate HTML parent element.
  4. Which property returns the next sibling?
    nextElementSibling.
  5. Why is firstElementChild preferred?
    Because it ignores text nodes and returns only HTML elements.
  6. What is an HTMLCollection?
    A live collection containing HTML elements only.
  7. Why is DOM traversal important?
    It helps efficiently access and manipulate webpage elements.
