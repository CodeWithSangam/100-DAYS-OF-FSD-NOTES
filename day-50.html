Day 50 - CSS Filters

🎥 Watch Tutorial #50

CSS Filters allow developers to apply visual effects such as blur, brightness, contrast, grayscale, hue rotation, opacity, and shadows directly to images and elements without using image editing software. Filters are widely used in modern web design to create attractive user interfaces, hover effects, galleries, cards, hero sections, and image processing effects. :contentReference[oaicite:0]{index=0}

What are CSS Filters?

CSS Filters are properties that apply graphical effects to HTML elements.

img{ filter: blur(5px); }

The image becomes blurred by 5 pixels.

Why Use CSS Filters?

  • Create visual effects.
  • Improve user experience.
  • Add interactivity.
  • Enhance images.
  • Build modern interfaces.

Syntax of Filter Property

filter:function(value);

Example

img{ filter:grayscale(100%); }

blur()

The blur() function applies a blur effect to an element.

img{ filter:blur(4px); }

Real World Usage

  • Background Images
  • Loading Screens
  • Glassmorphism Effects

brightness()

Controls the brightness of an element.

img{ filter:brightness(150%); }

Behavior

  • 100% = Original
  • Greater than 100% = Brighter
  • Less than 100% = Darker

contrast()

Adjusts the difference between light and dark areas.

img{ filter:contrast(200%); }

Applications

  • Photography Websites
  • Image Galleries
  • Hero Sections

grayscale()

Converts images into black and white.

img{ filter:grayscale(100%); }

Real World Usage

  • Portfolio Websites
  • Hover Effects
  • Creative Designs

invert()

Inverts colors of an image.

img{ filter:invert(100%); }

Usage

  • Dark Mode Icons
  • Creative Effects

opacity()

Controls transparency using the filter property.

img{ filter:opacity(50%); }

The image becomes semi-transparent.

saturate()

Controls color intensity.

img{ filter:saturate(200%); }

Meaning

  • 100% = Original
  • Above 100% = More Colorful
  • Below 100% = Less Colorful

sepia()

Applies an old photograph effect.

img{ filter:sepia(100%); }

Usage

  • Vintage Effects
  • Creative Photography

drop-shadow()

Adds shadow effects to elements.

img{ filter: drop-shadow(5px 5px 10px black); }

Benefits

  • Depth
  • Professional Appearance
  • Improved Visibility

hue-rotate()

Changes the color tone of an image.

img{ filter:hue-rotate(90deg); }

Real World Usage

  • Theme Effects
  • Creative Designs

Combining Multiple Filters

Multiple filter functions can be used together.

img{ filter: grayscale(100%) blur(2px) brightness(120%); }

Filters are applied from left to right.

Real World Applications

  • Image Galleries
  • Hero Sections
  • Cards
  • Portfolio Websites
  • Social Media Platforms
  • Dark Mode Icons
  • Modern UI Designs

Common Mistakes

  • Using excessive blur.
  • Combining too many filters.
  • Overusing brightness.
  • Reducing readability.
  • Ignoring performance impact.

Important Points

  • Filters create visual effects.
  • blur creates blur effects.
  • brightness changes brightness.
  • contrast adjusts contrast.
  • grayscale creates black-and-white images.
  • invert reverses colors.
  • drop-shadow adds depth.
  • Multiple filters can be combined.
  • Filters improve UI appearance.
  • Modern websites frequently use filters.
