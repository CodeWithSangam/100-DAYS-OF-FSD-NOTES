Day 71 - Inserting and Removing Elements Using JavaScript

🎥 Watch Tutorial #71

In this tutorial, we learn how JavaScript can dynamically insert, create, replace, and remove HTML elements from a webpage. These operations are a major part of DOM manipulation because real applications frequently add new content without reloading the page. Todo apps, shopping carts, chat applications, notifications, dashboards, comments, and dynamic forms all depend on inserting and removing elements through JavaScript.

What is Dynamic DOM Manipulation?

Dynamic DOM manipulation means changing the structure or content of a webpage using JavaScript after the page has loaded.

Select Parent Element ↓ Create or Insert Element ↓ Add Content and Attributes ↓ Place Element in DOM ↓ Remove or Replace When Required

Why Insert Elements Using JavaScript?

  • Add new todo items.
  • Display notifications.
  • Show API data.
  • Create product cards.
  • Add chat messages.
  • Build dynamic forms.
  • Update content without reloading the page.

Using innerHTML

The innerHTML property gets or replaces the HTML content inside an element.

let container = document.querySelector(".container"); container.innerHTML = "

Hello JavaScript

";

This replaces all existing content inside the selected container.

Important

  • It can insert HTML markup.
  • It replaces existing child content.
  • It should not be used with untrusted user input.

Using innerText

The innerText property reads or changes only the visible text inside an element.

let heading = document.querySelector("h1"); heading.innerText = "DOM Manipulation";

HTML tags passed through innerText are displayed as plain text.

Using textContent

The textContent property gets or sets all text content inside an element, including hidden text.

let paragraph = document.querySelector("p"); paragraph.textContent = "Updated paragraph content";
Property Behavior
innerHTML Reads or writes HTML markup
innerText Works with visible rendered text
textContent Works with all text content

Creating Elements with createElement()

The document.createElement() method creates a new HTML element in memory.

let newDiv = document.createElement("div"); console.log(newDiv);

The element exists in JavaScript memory but is not visible on the webpage until it is inserted into the DOM.

Adding Content to a Newly Created Element

let newDiv = document.createElement("div"); newDiv.innerHTML = "New Element";

Content can be added using innerHTML, innerText, or textContent.

Adding Classes to New Elements

let card = document.createElement("div"); card.className = "card";

You can also use classList:

card.classList.add("card", "active");

Adding Attributes

let link = document.createElement("a"); link.setAttribute("href", "[https://example.com](https://example.com)"); link.setAttribute("target", "_blank"); link.innerText = "Visit Website";

Attributes such as href, src, id, title, and data attributes can be added dynamically.

append()

The append() method inserts nodes or text at the end of a parent element.

let container = document.querySelector(".container"); let paragraph = document.createElement("p"); paragraph.innerText = "New paragraph"; container.append(paragraph);

Advantages

  • Can insert multiple nodes.
  • Can insert plain text.
  • Modern and flexible method.

appendChild()

The appendChild() method adds a single node as the last child of a parent element.

let container = document.querySelector(".container"); let button = document.createElement("button"); button.innerText = "Click Me"; container.appendChild(button);
append() appendChild()
Can insert nodes and text Inserts only a node
Can insert multiple values Inserts one node at a time
Does not return inserted node Returns inserted node

prepend()

The prepend() method inserts content at the beginning of an element.

let container = document.querySelector(".container"); let heading = document.createElement("h2"); heading.innerText = "First Element"; container.prepend(heading);

The new element becomes the first child of the container.

before()

The before() method inserts content before the selected element.

let box = document.querySelector(".box"); let heading = document.createElement("h2"); heading.innerText = "Inserted Before"; box.before(heading);

after()

The after() method inserts content after the selected element.

let box = document.querySelector(".box"); let paragraph = document.createElement("p"); paragraph.innerText = "Inserted After"; box.after(paragraph);

replaceWith()

The replaceWith() method replaces an existing element with a new node or text.

let oldHeading = document.querySelector("h2"); let newHeading = document.createElement("h3"); newHeading.innerText = "New Heading"; oldHeading.replaceWith(newHeading);

insertAdjacentHTML()

The insertAdjacentHTML() method inserts HTML at a specific position relative to an element.

let container = document.querySelector(".container"); container.insertAdjacentHTML( "beforeend", "

Inserted Paragraph

" );

Available Positions

Position Meaning
beforebegin Before the element itself
afterbegin Inside element, before first child
beforeend Inside element, after last child
afterend After the element itself

insertAdjacentText()

The insertAdjacentText() method inserts plain text at a specified position.

let container = document.querySelector(".container"); container.insertAdjacentText( "beforeend", "New text content" );

insertAdjacentElement()

The insertAdjacentElement() method inserts an existing element at a specified position.

let container = document.querySelector(".container"); let button = document.createElement("button"); button.innerText = "Submit"; container.insertAdjacentElement( "beforeend", button );

Removing Elements with remove()

The remove() method removes the selected element directly from the DOM.

let box = document.querySelector(".box"); box.remove();

The element and all of its child elements are removed.

Removing Child Elements with removeChild()

The removeChild() method removes a child node from its parent.

let parent = document.querySelector(".container"); let child = document.querySelector(".item"); parent.removeChild(child);

Difference

remove() removeChild()
Called on the element itself Called on the parent
Simpler modern method Requires child reference
No parent reference needed Parent reference required

Complete Dynamic Card Example

let container = document.querySelector(".container"); let card = document.createElement("div"); card.classList.add("card"); card.innerHTML = ` <h2>JavaScript Card</h2> <p>This card was generated dynamically.</p> <button>Remove</button>`; container.append(card);

This example creates a complete card element and adds it to the page.

let button = card.querySelector("button"); button.addEventListener("click", function(){ ``` card.remove(); ``` });

When the user clicks the button, the dynamically created card is removed from the DOM.

Best Practices

  • Use createElement() for safer element creation.
  • Prefer textContent for plain text.
  • Avoid innerHTML with untrusted user input.
  • Store parent elements in variables.
  • Use classList to manage CSS classes.
  • Remove unused DOM nodes.
  • Keep DOM updates minimal for better performance.

Common Mistakes

  • Creating an element but forgetting to append it.
  • Using innerHTML with unsafe input.
  • Removing the wrong element.
  • Using appendChild() with plain text.
  • Confusing beforeend with afterend.
  • Replacing all container content accidentally.
  • Adding duplicate IDs.

Important Points

  • createElement() creates a new DOM element.
  • append() inserts content at the end.
  • prepend() inserts content at the beginning.
  • before() inserts before an element.
  • after() inserts after an element.
  • replaceWith() replaces existing content.
  • insertAdjacentHTML() inserts HTML at specific positions.
  • remove() deletes an element directly.
  • removeChild() removes a child through its parent.
  • Dynamic insertion is essential for interactive applications.

Interview Questions

  1. What does document.createElement() do?
    It creates a new HTML element in memory.
  2. What is the difference between append() and appendChild()?
    append() supports multiple nodes and text, while appendChild() accepts one node.
  3. What does prepend() do?
    It inserts content at the beginning of a parent element.
  4. What is insertAdjacentHTML()?
    A method used to insert HTML markup at a specific position relative to an element.
  5. What are the four insertAdjacentHTML positions?
    beforebegin, afterbegin, beforeend, and afterend.
  6. What is the difference between remove() and removeChild()?
    remove() is called on the element itself, while removeChild() is called on the parent.
  7. Why should innerHTML be used carefully?
    Because untrusted input can create security risks such as cross-site scripting.
