JavaScript is one of the three core technologies of web development alongside HTML and CSS. HTML provides the structure of a webpage, CSS is responsible for styling, and JavaScript adds logic, interactivity, and dynamic behavior. In this tutorial, CodeWithHarry introduces JavaScript, explains why it is essential, demonstrates how to run JavaScript inside a browser, and shows how to install Node.js for executing JavaScript outside the browser. What is JavaScript?

JavaScript is a lightweight, interpreted programming language primarily used to make web pages interactive.

Examples of Interactivity

  • Button Click Events
  • Image Sliders
  • Dropdown Menus
  • Form Validation
  • Animations
  • Games
  • Chat Applications
  • Real-time Updates

The Three Pillars of Web Development

Technology Purpose
HTML Structure of Website
CSS Styling & Design
JavaScript Logic & Interactivity

Think of a human body:

  • HTML = Skeleton
  • CSS = Skin & Clothes
  • JavaScript = Brain

Why Do We Need JavaScript?

Without JavaScript, websites are mostly static. JavaScript makes websites interactive and responsive to user actions.

Uses

  • Handle button clicks.
  • Show alerts.
  • Validate forms.
  • Fetch data from servers.
  • Create games.
  • Build web applications.
  • Create animations.
  • Develop backend applications using Node.js.

Frontend vs Backend JavaScript

Frontend Backend
Runs in Browser Runs on Server
DOM Manipulation Database Handling
User Interface Business Logic
Browser APIs Node.js Runtime

What is Node.js?

Node.js is a JavaScript runtime environment that allows JavaScript code to run outside the browser.

Advantages

  • Backend Development.
  • Fast Execution.
  • NPM Package Manager.
  • Cross-platform Support.
  • Full Stack JavaScript Development.

Installing Node.js

The tutorial demonstrates installing Node.js from the official website.

Checking Installation

node -v

Displays the installed Node.js version.

npm -v

Displays the installed npm version.

Your First JavaScript Program

console.log("Hello World");

This prints "Hello World" inside the browser console or terminal.

Browser Console

Modern browsers provide Developer Tools where JavaScript can be executed.

F12 ↓ Console ↓ Write JavaScript

Uses

  • Testing Code.
  • Debugging.
  • Learning JavaScript.

alert()

Displays a popup message in the browser.

alert("Welcome to JavaScript");

Changing the Webpage Using JavaScript

document.title = "My Website";

Changes the title displayed on the browser tab.

document.body.style.background = "lightblue";

Changes the background color of the webpage dynamically.
