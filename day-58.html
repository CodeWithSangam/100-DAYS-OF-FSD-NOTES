Functions are one of the most important features of JavaScript. They allow developers to group reusable code into a single block that can be executed whenever needed. Instead of writing the same code repeatedly, we create a function once and call it multiple times. Functions improve readability, reduce code duplication, and make applications modular and easier to maintain. What is a Function?

A function is a reusable block of code that performs a specific task. It executes only when it is called.

function greet(){ console.log("Hello World"); }

Why Use Functions?

  • Reduce code repetition.
  • Improve readability.
  • Make programs modular.
  • Simplify debugging.
  • Reuse logic multiple times.
  • Improve maintainability.

Function Declaration

The most common way to create a function is using the function keyword.

function greet(){ console.log("Welcome"); } greet();

Output:

Welcome

Function Parameters

Parameters are variables that receive values when a function is called.

function greet(name){ console.log("Hello " + name); } greet("Sangam");

Output:

Hello Sangam

Arguments

Arguments are the actual values passed while calling a function.

function add(a,b){ console.log(a+b); } add(10,20);

Here 10 and 20 are arguments.

Return Statement

The return keyword sends a value back to the place where the function was called.

function add(a,b){ return a+b; } let result = add(5,10); console.log(result);

Output:

15

Function Expression

A function can also be stored inside a variable.

const multiply = function(a,b){ return a*b; } console.log(multiply(4,5));

Output

20

Arrow Functions (ES6)

Arrow functions provide a shorter syntax for writing functions.

const square = (num)=>{ return num*num; }

Shorter Version:

const square = num => num*num;

Advantages

  • Less code.
  • Easy to read.
  • Modern syntax.
  • Commonly used in React.

Default Parameters

Functions can define default values for parameters.

function greet(name="Guest"){ console.log("Hello " + name); } greet();

Output:

Hello Guest

Nested Functions

A function can be declared inside another function.

function outer(){ function inner(){ console.log("Inner"); } inner(); } outer();

Scope of Variables

Variables declared inside a function are called local variables and cannot be accessed outside the function.

function demo(){ let age = 20; } console.log(age);

Output:

ReferenceError

Best Practices

  • Keep functions short.
  • Use meaningful names.
  • One function should perform one task.
  • Reuse existing functions.
  • Return values instead of printing whenever possible.
  • Prefer arrow functions for simple callbacks.

Common Mistakes

  • Forgetting to call the function.
  • Missing return statements.
  • Using global variables unnecessarily.
  • Writing very large functions.
  • Passing incorrect arguments.

Important Points

  • Functions execute only when called.

  • Function expressions store functions inside variables.

Interview Questions

  1. What is a function?
    A reusable block of code that performs a specific task.
  2. What is the difference between parameters and arguments?
    Parameters are variables in the function definition, while arguments are the actual values passed during the function call.
  3. Why is the return statement important?
    It sends a value back to the caller.
  4. What is an arrow function?
    A shorter syntax for writing functions introduced in ES6.
  5. What is a function expression?
    A function assigned to a variable.
  6. Can a function return another function?
    Yes, JavaScript treats functions as first-class objects.
  7. Why should functions be small?
    Small functions are easier to understand, debug, and maintain.
