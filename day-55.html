What is a Variable?

A variable is a named container used to store data in memory. The stored value can later be read, modified, or used in calculations.

let name = "Sangam"; console.log(name);

Output:

Sangam

Why Do We Need Variables?

  • Store user information.
  • Perform calculations.
  • Reuse values.
  • Reduce code repetition.
  • Build dynamic applications.

Declaring Variables

JavaScript provides three ways to declare variables.

Keyword Can Reassign Can Redeclare Scope
let ✅ Yes ❌ No Block Scope
const ❌ No ❌ No Block Scope
var ✅ Yes ✅ Yes Function Scope

let Keyword

The let keyword is the recommended way to declare variables in modern JavaScript.

let age = 20; age = 21; console.log(age);

Advantages

  • Block scoped.
  • Can update value.
  • Safer than var.
  • Preferred in ES6.

const Keyword

Use const when the value should never be reassigned.

const pi = 3.14159; console.log(pi);
const pi = 3.14; pi = 5; ❌ Error

Best Use Cases

  • API URLs
  • Configuration
  • Constants
  • Fixed Values

var Keyword

The var keyword was used before ES6. Today it is generally avoided because of its function scope and redeclaration behavior.

var city = "Lucknow"; var city = "Delhi"; console.log(city);

Problems

  • Can be redeclared.
  • Function scoped.
  • Creates unexpected bugs.

Difference Between let, const and var

let marks = 80; marks = 90; ✅ Allowed
const country = "India"; country = "USA"; ❌ Not Allowed
var language = "JS"; var language = "Python"; ✅ Allowed

Using typeof Operator

The typeof operator returns the type of a value.

let age = 20; console.log(typeof age);

Output

number

The typeof null Mystery

One of JavaScript's famous historical bugs is that typeof null returns "object". This behavior exists for backward compatibility and is considered a language quirk. :contentReference[oaicite:1]{index=1}

console.log(typeof null);

Output

object

JavaScript Objects

Objects store multiple related values using key-value pairs.

let student = { name:"Sangam", age:20, college:"XYZ", cgpa:8.21 };

Accessing Object Properties

console.log(student.name); console.log(student.age);

Output

Sangam 20

Updating Objects

student.age = 21; student.city = "Lucknow";

Objects can be modified even when declared using const; only the variable reference cannot be reassigned.

Best Practices

  • Prefer const by default.

  • Avoid var in modern JavaScript.

Common Mistakes

  • Confusing null and undefined.

  • Using unclear variable names.
  • Ignoring data types.

Interview Questions

  1. What is a variable?
    A named container used to store data.
  2. What is the difference between let and const?
    let allows reassignment while const does not.
  3. Why should var be avoided?
    Because it is function-scoped and allows redeclaration.
  4. How many primitive data types are there in JavaScript?
    Seven.
  5. Why does typeof null return "object"?
    Because of a historical JavaScript bug kept for backward compatibility.
  6. What is an object?
    A collection of key-value pairs.
  7. Can a const object be modified?
    Yes, its properties can be changed, but the reference cannot be reassigned.
