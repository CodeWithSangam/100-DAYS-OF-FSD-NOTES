Day 59 - Exercise 9: Faulty Calculator

🎥 Watch Tutorial #59

Exercise 9 is a JavaScript logic-building challenge. The goal is to create a calculator that usually performs correct mathematical operations but intentionally gives incorrect answers approximately 10% of the time. This exercise helps students practice conditional statements, random number generation, functions, operators, and problem-solving skills. Unlike previous tutorials that focused on syntax, this exercise emphasizes algorithmic thinking and writing complete JavaScript programs. :contentReference[oaicite:1]{index=1}

Exercise Objective

Create a calculator that:

  • Accepts two numbers.
  • Accepts an operator (+, -, *, /).
  • Returns the correct result 90% of the time.
  • Returns an intentionally wrong result 10% of the time.

Generating Random Numbers

JavaScript provides the Math.random() method for generating random decimal numbers.

let random = Math.random(); console.log(random);

Output will be between:

0 ↓ 0.999999...

Using Random Numbers for Decisions

if(random > 0.1){ // Correct Result } else{ // Faulty Result }

Since 90% of generated numbers are greater than 0.1, the calculator behaves correctly most of the time.

Using Objects for Wrong Operations

Instead of writing multiple if-else statements, incorrect operators can be stored inside an object.

let faulty = { "+":"-", "*":"+", "-":"/", "/":"**" };

The object maps correct operators to incorrect ones.

Calculator Logic

Take Input ↓ Generate Random Number ↓ Random > 0.1 ? ↓ Yes → Correct Calculation ↓ No → Faulty Calculation

Example Output

Input 10 + 5 Correct Output 15 Faulty Output 5
